# 📖 Selector Bíblico Web

Una aplicación web rápida, segura y sin dependencias para explorar pasajes bíblicos. Funciona offline y está optimizada para móviles.

## 🚀 Características
- ✅ **Óptima**: Carga instantánea, sin frameworks pesados.
- 🔒 **Segura**: Sin backend, sanitización de entradas contra XSS.
- 📱 **Responsive**: Se adapta a cualquier pantalla.
- 🌙 **Modo Oscuro**: Incluido por defecto.

## 🛠️ Cómo usarla
1. Clona este repositorio: `git clone https://github.com/tu-usuario/mi-app-biblica.git`
2. Abre el archivo `public/index.html` en tu navegador.
3. ¡Listo! No requiere instalación ni servidor.

## 📂 Estructura del proyecto
- `public/`: Archivos de despliegue.
- `src/`: Código fuente organizado (CSS, JS, datos).
